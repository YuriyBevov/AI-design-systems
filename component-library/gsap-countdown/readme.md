# GSAP Countdown

Обратный отсчет с плавной GSAP-анимацией смены цифр и русскими падежами подписей: `1 час`, `3 часа`, `5 часов`.

Компонент работает с двумя режимами:

- `data-countdown-duration` — длительность в секундах от момента загрузки страницы;
- `data-countdown-deadline` — фиксированная дата окончания в формате, который понимает `new Date()`;
- `data-countdown-schedule="workweek-msk"` — недельный режим: старт в понедельник в 08:00 по МСК, окончание в пятницу в 20:00 по МСК. Вне этого окна счетчик показывает нули.

## Файлы

- `html.html` — пример разметки.
- `scss.scss` — исходные стили компонента.
- `css.css` — скомпилированные стили для быстрого подключения.
- `js.js` — переносимый JS-модуль.

## Подключение

```js
import { initGsapCountdown } from "./js.js";

initGsapCountdown();
```

## Options

```js
initGsapCountdown({
	rootSelector: ".countdown",
	itemSelector: ".countdown__item",
	valueSelector: "[data-countdown-value]",
	labelSelector: "[data-countdown-label]",
	duration: 0.45,
	ease: "power2.out",
});
```

Для каждой единицы времени укажите `data-countdown-unit`: `days`, `hours`, `minutes` или `seconds`.

Таймер не использует фиксированный `setInterval(1000)`: каждый следующий тик планируется по оставшемуся времени до следующей секундной границы. Это снижает дрейф таймера и не дает секундам подвисать или перескакивать при обычной работе вкладки.

Компонент не делает сетевых запросов: внутри не должно быть `fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket` или других способов загрузки данных. Его зона ответственности — только расчет оставшегося времени, обновление текста и GSAP-анимация цифр.

После первичной подготовки DOM компонент не должен пересоздавать цифры на каждом тике через `append`, `remove` или `replaceChildren`. Обычная смена значения выполняется через обновление `nodeValue` существующих текстовых узлов внутри символов, чтобы не провоцировать лишние `childList`-мутации в dev-инструментах.
