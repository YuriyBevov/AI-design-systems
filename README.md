# AI Design Systems

Дизайн-проекты для разработки сайтов через ИИ-агента.

## Структура

```
pen.dev/     — .pen файлы (дизайн-макеты для pen.dev)
```

## Как работать

1. Рисуете макет в pen.dev → сохраняете .pen файл
2. Помещаете его в `pen.dev/`
3. Агент читает .pen файл → генерирует SCSS + шаблоны
4. Правки вносите визуально в pen.dev или через агента в .pen файле
