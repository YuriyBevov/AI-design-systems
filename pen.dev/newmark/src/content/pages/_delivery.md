# Оплата и доставка

Шаблон статичной страницы для условий оплаты, доставки, самовывоза и другой справочной информации.

## Назначение страницы

Этот шаблон используется для статичных страниц сайта: о компании, доставке, оплате, производстве, контактах и юридических разделах.

Контент страницы хранится отдельно от шаблона, поэтому новые страницы можно добавлять через Markdown-файлы.

## Что можно разместить на странице

- текстовое описание;
- списки условий или преимуществ;
- этапы работы;
- таблицы параметров;
- FAQ;
- контактную информацию;
- изображения и слайдеры.

## Минимальные поля страницы

| Поле | Назначение |
| --- | --- |
| `slug` | URL страницы латиницей |
| `seoTitle` | содержимое тега `title` |
| `seoDescription` | описание для `meta description` |
| `#` | единственный основной заголовок страницы |

## FAQ для шаблона

**Где располагается форма заявки?**

Форма заявки выводится сквозным блоком перед футером и не добавляется в данные статичной страницы.

**Можно ли добавить несколько `h1`?**

Нет. На каждой странице проекта допускается только один `h1`.
