# Общие данные сайта Newmark

Эта папка хранит общие данные, которые используются в шапке, футере и статичных страницах.

## Файлы

- `contacts.js` - телефоны, email, график работы и адреса;
- `socials.js` - ссылки на социальные сети и настройки иконок из SVG-спрайта;
- `legal.js` - копирайт и юридические ссылки футера;
- `index.js` - единая точка экспорта для компонентов.

## Правила

- Клиентские правки общих контактов, соцсетей и юридической информации вносятся здесь, а не в компонентах.
- `href` для телефона указывается в формате `tel:+70000000000`.
- `href` для email указывается в формате `mailto:sales@example.ru`.
- `icon` в соцсетях должен совпадать с id символа в SVG-спрайте.
- Если ссылка пока неизвестна, можно временно оставить `href: "#"`.
