# Проектные инструкции для ИИ Newmark

Эта папка хранит внутренние инструкции для ИИ-агентов, которые работают именно с проектом Newmark.

Эти документы не смешиваются с общими гайдами из корневой папки `guides/`. Общие гайды задают базовые правила верстки, именования, CSS/SCSS и поведения агента. Проектные гайды уточняют, как создавать и наполнять страницы Newmark: каталог, разделы, товары и статичные страницы.

Перед началом работы агент должен:

- прочитать общие гайды из корневой папки `guides/`;
- проверить наличие папки `guides/` внутри текущего проекта;
- прочитать проектные инструкции, если они есть;
- применять проектные инструкции вместе с общими гайдами;
- при противоречии не принимать решение молча, а явно зафиксировать конфликт и выбрать безопасный вариант.

Планируемые файлы:

- `ai-content-global.md` - общие правила AI-наполнения Newmark;
- `ai-static-page.md` - создание статичной страницы;
- `ai-catalog-page.md` - обновление страницы каталога;
- `ai-catalog-section.md` - создание и обновление раздела каталога;
- `ai-product-page.md` - создание и обновление товара;
- `ai-images.md` - правила работы с изображениями;
- `ai-checklist.md` - финальная проверка после изменений.
