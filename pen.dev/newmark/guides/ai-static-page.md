# Создание статичной страницы Newmark

Гайд описывает порядок добавления статичных страниц через Astro-шаблон `StaticPage.astro`.

## Где хранится контент

Данные статичных страниц лежат в:

```text
src/content/pages/
```

Каждая страница хранится отдельным JSON-файлом. Имя файла должно совпадать со slug страницы.

Пример:

```text
src/content/pages/delivery.json
```

## Как формируется URL

URL берется из поля `slug`.

Примеры:

- `delivery` → `/delivery/`;
- `about` → `/about/`;
- `payment` → `/payment/`.

Slug пишется латиницей, в нижнем регистре, слова разделяются дефисом.

## Обязательные поля

- `slug` - URL страницы;
- `title` - внутреннее название страницы;
- `seoTitle` - содержимое тега `title`;
- `seoDescription` - содержимое `meta description`;
- `breadcrumbs` - хлебные крошки;
- `h1` - единственный основной заголовок страницы;
- `lead` - вводный текст;
- `contentBlocks` - массив контентных блоков;
- `cta.enabled` - показывает, нужен ли CTA-блок.

## Поддерживаемые блоки

- `text` - текстовый блок с заголовком и абзацами;
- `image` - изображение с подписью;
- `list` - обычный маркированный список;
- `steps` - нумерованный список этапов;
- `table` - таблица параметров;
- `faq` - список вопросов и ответов;
- `contacts` - контактная информация;
- `cta` - задается через корневое поле `cta`, а не внутри `contentBlocks`.

## Вопросы пользователю

Перед созданием страницы ИИ должен запросить:

- название страницы;
- slug;
- h1;
- SEO title;
- SEO description;
- вводный текст;
- какие контентные блоки нужны;
- тексты для каждого блока;
- нужен ли CTA;
- текст CTA и ссылку для кнопки;
- нужны ли изображения;
- alt-тексты для изображений;
- есть ли формулировки, которые нельзя редактировать.

## Проверка

После создания страницы ИИ должен проверить:

- страница собирается через `npm run build`;
- на странице только один `h1`;
- нет пустых блоков;
- хлебные крошки соответствуют URL;
- все изображения имеют `alt`;
- CTA отключен, если для страницы он не нужен;
- видимый текст соблюдает правила типографики проекта.
