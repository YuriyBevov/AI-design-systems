# Общие правила AI-наполнения Newmark

Документ задает базовый порядок работы ИИ с контентом проекта Newmark.

## Основной принцип

ИИ не придумывает недостающие факты о компании, товарах, ценах, сроках, акцизности, наличии и условиях заказа. Если данных нет, ИИ задает вопросы пользователю.

## Порядок работы

1. Определить тип задачи: статичная страница, каталог, раздел каталога или товар.
2. Найти соответствующий проектный гайд в `pen.dev/newmark/guides/`.
3. Проверить, какие данные обязательны.
4. Задать пользователю вопросы по недостающим обязательным данным.
5. Отделить обязательные вопросы от дополнительных.
6. Внести данные в структуру проекта.
7. Проверить страницу по чеклисту.
8. Зафиксировать изменения в `agent-conversation-history.md`.

## Общие требования

- У каждой страницы только один `h1`.
- Slug пишется латиницей в нижнем регистре.
- Слова в slug разделяются дефисом.
- Все изображения должны иметь осмысленный `alt`.
- SEO title и SEO description должны быть уникальными для каждой страницы.
- Условия заказа, минимальная партия и срок производства оформляются как уточнение, если они показываются рядом с карточкой или товаром.
- Видимый текст должен соблюдать правила типографики проекта.

## Что нельзя делать

- добавлять товар без раздела каталога;
- добавлять изображения без `alt`;
- придумывать цену, сроки, наличие или характеристики;
- создавать несколько `h1` на странице;
- смешивать проектные инструкции Newmark с общими гайдами репозитория.
