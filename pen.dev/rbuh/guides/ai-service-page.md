# Услуги и детальные страницы

## Назначение

Услуга — повторяемая сущность. Новая услуга добавляется объектом данных и автоматически получает карточку, URL, хлебные крошки и детальную страницу.

## Обязательные поля услуги

- стабильный `id`;
- уникальный `slug`;
- название;
- короткое описание для карточки;
- изображение и `alt`;
- вводный текст детальной страницы;
- полное описание;
- SEO title и description;
- список FAQ либо пустой массив;
- признак показа карты.

Цена не хранится в объекте услуги. Она связывается через `serviceId`.

## Необязательные поля

- галерея;
- список особенностей;
- параметры услуги;
- CTA-текст;
- связанные услуги;
- примечание об индивидуальном расчёте.

## Минимальная структура

```js
{
  id: "pump",
  slug: "avtobetononasos",
  title: "Услуги автобетононасоса",
  shortDescription: "...",
  image: {
    src: "service-pump.webp",
    alt: "Автобетононасос подаёт бетон на строительной площадке"
  },
  detail: {
    lead: "...",
    description: ["..."],
    features: [],
    faqIds: [],
    mapEnabled: true
  },
  seo: {
    title: "...",
    description: "..."
  }
}
```

## Создание услуги

1. Проверить, нет ли похожей услуги.
2. Получить обязательные данные.
3. Создать уникальные `id` и `slug`.
4. Подготовить или сгенерировать изображение по `ai-images.md`.
5. Добавить объект услуги.
6. Добавить FAQ только при наличии достоверных ответов.
7. Добавить связанные группы цен по `ai-price-list.md`.
8. Проверить карточку на главной и `/services/`.
9. Проверить детальную страницу и хлебные крошки.

## Шаблон детальной страницы

1. Хлебные крошки.
2. Медиа и summary в двух колонках на широком экране.
3. `h1`, lead, подтверждённые параметры и CTA.
4. Полное описание.
5. Таблица цен из общего источника.
6. FAQ услуги.
7. Карта, если включена.

Если галерея состоит из одного кадра, не показывать неработающие стрелки. Sticky-медиа допустимо только если не мешает чтению и не обрезается на низких экранах.

## Обязательные вопросы пользователю

- точное название услуги;
- что входит и что не входит;
- условия заказа;
- единица расчёта;
- цены или разрешённая формулировка «По запросу»;
- ограничения техники/доставки;
- территория работы;
- изображение можно считать реальным или нужно сгенерировать;
- есть ли юридически/технически точные формулировки.

## Проверка

- URL уникален;
- на странице один `h1`;
- цена совпадает с полным прайсом;
- единицы измерения указаны;
- FAQ не противоречит описанию;
- изображение имеет правильный источник и `alt`;
- карта включается настройкой;
- кнопка открывает единую форму с полями «Имя», «Телефон» и необязательным комментарием.
