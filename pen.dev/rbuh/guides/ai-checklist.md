# Финальный чеклист

## Данные и бренд

- [ ] Используется подтверждённое название РБУ «Хаджох».
- [ ] Материал называется «мешанка».
- [ ] В публичном коде нет Newmark, «НЬЮМАРК» и текстов про упаковку.
- [ ] Контакты, адрес и режим работы берутся из `src/content/site/`.
- [ ] Реквизиты и юридические тексты не выдуманы.
- [ ] Временные карточки отзывов хранятся централизованно и готовы к замене подтверждёнными данными.

## Маршруты

- [ ] Работают `/`, `/services/`, `/price/`.
- [ ] Работает каждая `/services/[slug]/`.
- [ ] Работают все обязательные статичные страницы.
- [ ] Навигация и хлебные крошки не ведут на 404.
- [ ] У каждой страницы один `h1`.

## Компоненты и данные

- [ ] Главная и `/services/` используют один `ServicesGrid`.
- [ ] Все услуги формируются из данных.
- [ ] Цены на детальных страницах и `/price/` имеют один источник.
- [ ] Все `serviceId` и `faqIds` валидны.
- [ ] Нет дублирующихся `id` и `slug`.
- [ ] В компонентах нет хардкода общих контактов и цен.

## Изображения

- [ ] `img/hero.jpeg` используется в hero.
- [ ] Оригиналы в `img/` сохранены.
- [ ] Локальные изображения оптимизированы.
- [ ] Hero имеет eager/high priority; остальные изображения ленивые по умолчанию.
- [ ] Заданы размеры и нет заметного CLS.
- [ ] Все смысловые изображения имеют корректный `alt`.
- [ ] Сгенерированные ассеты отмечены в манифесте.
- [ ] Генерации визуально проверены на артефакты.

## Логотип и дизайн

- [ ] Логотип — SVG без растра и внешнего шрифта.
- [ ] Логотип читается в шапке, футере и мобильном меню.
- [ ] Палитра заменена на утверждённую индустриальную.
- [ ] Контраст соответствует WCAG AA.
- [ ] `:focus-visible` заметен.
- [ ] Сниженное движение учитывает `prefers-reduced-motion`.

## Внешние блоки

- [ ] Карта имеет `title`, lazy-loading и режим `noscroll`, не содержит видимой подписи и занимает ширину и высоту экрана.
- [ ] Временные координаты явно отмечены в данных.
- [ ] Блок отзывов не загружает сторонний код без конфигурации.
- [ ] Карточки отзывов содержат аватар, ФИО, рейтинг, дату и текст без `blockquote`.

## Формы

- [ ] Обязательны только имя и телефон; комментарий необязателен.
- [ ] Клиентская и серверная схемы совпадают.
- [ ] Под формой есть ссылка на политику конфиденциальности.
- [ ] Ошибки и успех доступны для скринридера.
- [ ] Модальное окно удерживает фокус и возвращает его при закрытии.
- [ ] Обратный отсчёт работает ежедневно с 08:00 до 21:00 по Москве и обнуляется вне этого интервала.
- [ ] В текущей версии таймера дни скрыты настройкой `countdownConfig.showDays`; при необходимости их можно вернуть без изменения разметки.
- [ ] Секреты отсутствуют в Git.

## Адаптив и качество

- [ ] Проверены 360, 768, 1024 и 1440 px.
- [ ] Нет горизонтальной прокрутки страницы.
- [ ] Карточки услуг сохраняют ключевые объекты кадра и читаемый текст на подложке.
- [ ] Кнопка возврата наверх появляется после прокрутки первого экрана.
- [ ] Таблицы цен читаются на мобильном.
- [ ] Меню, FAQ, модальные окна, ссылки и кнопки работают с клавиатуры.
- [ ] Нет ошибок и 404 в консоли/сети.
- [ ] `npm run build` завершается успешно.
- [ ] В отчёте перечислены временные данные и неподключённые интеграции.
