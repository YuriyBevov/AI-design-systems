# Проектные инструкции РБУ «Хаджох»

Эта папка содержит инструкции для реализации и дальнейшего AI-наполнения сайта.

Перед изменениями агент должен:

1. Прочитать общие правила репозитория из `../../../guides/`.
2. Прочитать `../technical-task.md`.
3. Прочитать `architecture.md` и гайд, соответствующий типу задачи.
4. Проверить обязательные данные. Если владелец уже разрешил временные заглушки, не запрашивать те же данные повторно, а сохранить явные `TODO`.
5. Не переносить публичный контент Newmark в новый сайт.
6. После изменений выполнить `ai-checklist.md` и зафиксировать результат проверки.

## Файлы

- `architecture.md` — структура проекта и правила переиспользования Newmark;
- `implementation.md` — последовательность создания сайта;
- `ai-content-global.md` — общие правила работы с контентом;
- `ai-home-page.md` — главная страница и её блоки;
- `ai-service-page.md` — карточки и детальные страницы услуг;
- `ai-price-list.md` — единая модель цен и прайс-лист;
- `ai-static-page.md` — статичные Markdown-страницы;
- `ai-information.md` — публикации раздела «Информация», теги и поиск;
- `ai-images.md` — реальные и сгенерированные изображения, SVG-логотип;
- `ai-checklist.md` — финальная проверка.

## Приоритет инструкций

Факты и прямые указания пользователя важнее примеров в документах. При конфликте требований нужно остановить спорную часть работы, зафиксировать конфликт и запросить решение. Нельзя молча заменять подтверждённые данные предположениями.
