# Раздел «Информация»

Адрес списка: `/information/`. Адрес статьи: `/information/<slug>/`.
Ссылки на раздел расположены в левом меню футера и мобильном меню.

## Новая публикация

1. Скопировать `src/content/information/_template.md` в новый Markdown-файл без начального подчёркивания.
2. Заполнить уникальный `slug` латиницей с дефисами, `title`, `description` и массив `tags`.
3. Добавить проверенный текст. H1 выводится из title; Markdown начинается с абзаца или `##`.
4. Установить `draft: false` и выполнить `npm run build`.

Один тег: `tags: [Бетон]`. Несколько тегов: `tags: [Бетон, Марки бетона, Прочность]`.
Теги появляются в фильтре автоматически. Дубликаты, лишние пробелы и варианты регистра объединяются.
Необязательный `seoTitle` переопределяет заголовок вкладки; description используется в метаданных.
Файлы с начальным подчёркиванием и записи с `draft: true` не публикуются.
Нельзя придумывать нормативные характеристики, марки продукции компании и методы её лаборатории.

## Поиск

- Поиск по заголовку, описанию, тегам и тексту статьи без учёта регистра; е и ё равнозначны.
- Все слова запроса должны присутствовать в записи, порядок не важен.
- Несколько выбранных тегов находят записи хотя бы с одним из этих тегов.
- Текстовый запрос и выбранные теги работают совместно.
- Параметры `q` и повторяющийся `tag` сохраняются в URL.
- С JavaScript список обновляется при вводе и выборе тегов. Без JavaScript те же фильтры применяются кнопкой «Найти» на сервере.
- Статьи упорядочены по заголовку. Для публикации нового файла необходима пересборка.

Проверки: `node --test scripts/test-information.mjs`, `npm run build`.
Начальный шаблон является черновиком; публичные статьи добавляются после подготовки текстов.
